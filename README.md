# BookVault-Full-Stack-Book-Management-System
A full-stack web application built with Angular and ASP.NET Core that allows users to perform CRUD operations (Create, Read, Update, Delete) on books through a RESTful API using an in-memory data store.


# Book Manager (Angular + ASP.NET Core)

A simple full-stack web application to manage a list of books.  
Users can create, view, update, and delete books.

## Technologies

- Frontend: Angular, TypeScript, HTML, CSS
- Backend: ASP.NET Core Web API, C#
- Storage: In-memory list (no database)
