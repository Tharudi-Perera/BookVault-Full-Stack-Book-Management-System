What I Built

A complete CRUD system,
from scratch.

BookVault demonstrates end-to-end full-stack development — a standalone Angular frontend consuming a RESTful ASP.NET Core API, connected seamlessly with clean component architecture and real-time form validation.

🧱

Standalone Architecture

Used Angular 17 standalone components instead of NgModules — the modern, recommended approach that reduces boilerplate and improves tree-shaking.

🔗

RESTful API Design

The backend exposes clean GET, POST, PUT, DELETE endpoints following REST conventions, documented interactively through Swagger / OpenAPI.

🛡️

Validation on Both Ends

Client-side real-time validation with Angular's ReactiveFormsModule prevents bad data before it's sent. The API independently validates before processing.

🎨

Custom UI — Zero Libraries

No Bootstrap, no Material. The entire dark-themed UI — sidebar, animated form panel, custom modal — is hand-crafted with pure CSS3.

⚙️

Service-Based API Layer

Angular services abstract all HTTP calls using RxJS Observables, keeping components clean and making the API layer fully reusable and testable.

🚀

Production-Ready Patterns

Strong TypeScript interfaces, consistent naming conventions, no direct DOM manipulation, and a custom confirmation modal replacing native browser dialogs.
